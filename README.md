# EWB student chapter website

The website for our Engineers Without Borders student chapter, hosted on GitHub Pages.

**Officers:** to update the site, read [docs/OFFICER-GUIDE.md](docs/OFFICER-GUIDE.md). No coding needed.

## Launching (one time)

1. Name this repository `<org-name>.github.io` so the site is at `https://<org-name>.github.io`.
2. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Set `url` in `_config.yml` to the site address.
4. Optional: add a custom domain under **Settings → Pages**.
